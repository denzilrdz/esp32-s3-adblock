🛡 AdBlock web installer

Flash the DNS ad blocker onto an ESP32-S3 with 16 MB flash and 8 MB octal PSRAM (DevKitC-1 N16R8) straight from the browser. Works in Chrome or Edge on a desktop (Web Serial).

  1. Connect the board with a data USB cable (on the DevKitC-1, use the port marked UART).
  2. Click the button and pick the serial port. Erasing the device is recommended for a first install.
  3. When it finishes, join the S3-AdBlock-XXXX Wi-Fi from a phone and pick your network.
  4. Open the serial console (the installer can show logs) to read the one-time dashboard setup code.

Then point your router's DNS at the device. See the README and the router setup guide (including the IPv6 caveat).
