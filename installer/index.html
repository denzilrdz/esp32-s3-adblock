AdBlock

Block ads for every device on your network

Flash the DNS ad blocker onto an ESP32-S3 straight from your browser. It blocks ads and trackers for every device and forwards everything else over encrypted DNS.

  • Version __VERSION__
  • ESP32-S3 DevKitC-1 N16R8
  • 16 MB flash · 8 MB PSRAM
  • Chrome or Edge on a desktop

Connect the board, then click Install. Pick the serial port; erasing the device is recommended for a first install. Takes about a minute.

This browser can't talk to USB serial devices. Open this page in Chrome or Edge on a desktop (Web Serial). Web Serial needs a secure page: open this installer over https://.

Steps

  1. Plug in the board Use a data USB cable and, on the DevKitC-1, the port marked UART.
  2. Install Click Install AdBlock, pick the serial port and wait for it to finish.
  3. Join it to your Wi-Fi From a phone, join the S3-AdBlock-XXXX network. A setup page opens; pick your network and enter its password.
  4. Get the dashboard setup code Click the button again, pick the port, then Logs & Console (press Reset Device there if it stays empty). Don't choose Install again. Open http://s3adblock.local and set a password with that code.
  5. Point your router's DNS at the board See the router setup guide, including the IPv6 caveat.

Troubleshooting

No serial port appears
  • Use a data cable, not a charge-only one.
  • If the board's red LED stays off or blinks, turn the USB-C plug over: some boards only work one way round.
It can't connect or the install fails
  • Hold BOOT, tap RST, release BOOT and try again.
  • Close other programs using the port (serial monitors, the Arduino IDE).
Already running AdBlock?
  • No need to come back here: the dashboard checks for new versions when it opens and installs them over the air, keeping your settings.
